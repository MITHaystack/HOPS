Non-Configurable Pipeline Operators
====================================

Non-configurable operators form the internal core of the fringe-fitting pipeline.
They are not triggered by control file keywords but are instantiated and executed
automatically by the fringe fitter at fixed points in the processing chain.
These include the normalization and FFT steps that transform visibility data
from frequency space to delay/delay-rate space, the coarse and fine peak search
operators, and internal labeling steps.

Documentation for these operators is still in progress and is not yet included.
