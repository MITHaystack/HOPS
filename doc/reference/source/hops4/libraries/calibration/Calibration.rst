Calibration Library
===================

The calibration library (``libMHO_Calibration``) provides the C++ implementation
of all operator classes used in the HOPS4 fringe-fitting pipeline.

For full reference documentation of each operator, including purpose, control
file keywords, input/output data types, and configuration parameters, see the
:ref:`CalibrationOperatorReference`.

The calibration library also contains utility classes (``MHO_StationModel``,
``MHO_DelayModel``) for computing a priori delay model quantities needed during
fringe fitting. These are documented in the
:ref:`CalibrationOperatorReference` under *Utility Classes*.
